# PDAC Transcriptomic and Network Analysis

This repository contains the full set of materials used to perform a transcriptomic and network-based analysis of pancreatic ductal adenocarcinoma (PDAC). The project integrates differential expression analysis, gene co-expression network reconstruction, modular clustering, functional enrichment, and survival-based validation in order to prioritise biologically relevant hub genes with potential translational interest.

## Project overview

The workflow was developed to analyse paired tumour and adjacent normal pancreatic samples from the GSE28735 dataset and to validate candidate genes in TCGA-PAAD. The analysis includes:

- Differential expression analysis using an empirical-Bayes framework.
- Construction of a tumour-specific gene co-expression network.
- MCL-based community detection in Cytoscape.
- Functional enrichment analysis with WebGestalt.
- Topological hub selection using multiple centrality measures.
- Survival analysis in an independent cohort.
- Literature-based prioritisation of novel candidate genes.

## Repository contents

The repository is organised to support transparency, reproducibility, and inspection of the full analytical pipeline.

- `proyecto_TFG_final_v8.ipynb`: Main Jupyter notebook containing the complete analysis workflow.
- `analisis_limma.R`: R script used for the limma-based differential expression analysis.
- `webgestalt_results/`: Functional enrichment tables for each MCL cluster.
- `cytoscape_session.cys`: Cytoscape session file containing the network and clustering layout.
- `thesis_outputs/`: All figures and tables produced during the project

## Reproducibility

The notebook and R script were executed in a controlled Python and R environment. Randomness was fixed using `SEED = 42` to ensure reproducibility of the computational steps where applicable. Version information for Python, R, and the main libraries is documented in the notebook output and should be consulted before rerunning the pipeline.

## How to use this repository

1. Open the main Jupyter notebook.
2. Run the notebook sequentially from top to bottom.
3. Run the `analisis_limma.R` script if you want to reproduce the differential expression analysis independently.
4. Verify that the required input files are present in the expected paths.
5. Review the output tables and figures generated by each analysis step.
6. Consult the annex files for extended results and supporting material.
